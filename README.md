# 스마트장부

네이버 스마트스토어와 쿠팡 판매내역·주문·상품·정산·손익을 한 프로그램에서 관리하는 Windows 앱입니다.

## 다운로드

[최신 스마트장부 설치파일 받기](https://github.com/wownd3615/store-manager-releases/releases/latest)

- Windows 10/11 64비트
- 장부 DB, 판매처 API 키와 로그인 세션은 설치파일에 포함하지 않습니다.
- 1.0.23부터 새 버전이 공개되면 앱 시작 시 검증된 필수 업데이트를 안내합니다.
- 설치파일은 HTTPS로 내려받고 공개된 SHA-256과 일치할 때만 설치합니다.
